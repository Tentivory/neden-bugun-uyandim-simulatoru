# Neden Bugün Uyandım Simülatörü

Bu proje, insanlığın en büyük sorusuna cevap vermek için tasarlanmıştır: **Bugün neden uyandım?**

## Özellikler
- %99.9 doğruluk oranı (geri kalan %0.1'i de yalandır)
- Sonsuz düşünme süresi
- Rastgele absürt cevaplar
- Hiçbir işe yaramaz ama çok ciddi görünür
- Python 3 ile çalışır (umarım)

## Kullanım
```bash
python neden_uyandim.py
```

Program sizi bekletecek, düşünecek ve sonunda size hayatınızın anlamını (veya anlamsızlığını) söyleyecek.

## Bilimsel Temel
Bu simülatör, kuantum mekaniği, varoluşçuluk ve sabah kahvesi arasındaki gizemli bağlantıyı inceler. Hiçbir bilimsel kanıt yoktur ama yine de çok ikna edicidir.
